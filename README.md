## How to view

GitHub shows HTML files as code, so download them first.

1. Open a file above and select **Download raw file**.
2. Open the downloaded file in Chrome, Edge or Safari.
3. Press **F** for full screen. **→**, Space or a click moves forward; **←** goes back; **G** opens the slide index.

The files need the internet only for fonts. Offline, they fall back to system fonts.
