## How to view

1. Open the hub link above in Chrome, Edge or Safari.
2. In a deck, press **F** for full screen. **→**, Space or a click moves forward; **←** goes back; **G** opens the slide index.
3. To link straight to one slide, add its name after `#`. For example, `…/LJC-Design-Innovation_Revised-Plan_DRAFT.html#year` opens the Timeline. The hub's slide previews link this way.

The files need the internet only for fonts. Offline, download a file (**Download raw file** on GitHub) and open it from your computer; it falls back to system fonts.
